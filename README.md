# TextPlay

A simple and interactive Text Formatter built using HTML, CSS, and JavaScript. 

## Features

- **Uppercase:** Convert text to uppercase.
- **Lowercase:** Convert text to lowercase.
- **Capitalize:** Capitalize the first letter of every word.
- **Bold:** Toggle bold formatting on and off.
- **Italic:** Toggle italic formatting on and off.
- **Underline:** Toggle underline formatting on and off.
- **Copy Text:** Copy the formatted text to the clipboard.
- **Reset Formatting:** Restore the original text and remove all formatting.
- **Interactive Buttons:** Active formatting buttons are highlighted visually.
- **Live Preview:** View your text in the output area as you type.

## Technologies Used

- **HTML5** — Structures the application.
- **CSS3** — Styles the interface and provides responsive layouts.
- **JavaScript** — Handles text transformations, button interactions, and clipboard functionality.
